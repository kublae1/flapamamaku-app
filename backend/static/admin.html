Benutzer & Berechtigungen

Neues Konto: temporäres Passwort mit mindestens 8 Zeichen eingeben. Das Mitglied muss es beim ersten Login ändern. Bestehender Benutzer: Feld leer lassen, wenn das Passwort unverändert bleibt. Wird hier ein neues Passwort gesetzt, werden bestehende Sitzungen beendet und beim nächsten Login ist ebenfalls eine Passwortänderung Pflicht. Das bisherige Passwort kann aus Sicherheitsgründen nicht angezeigt oder ausgelesen werden.

Die Rolle liefert die Standardrechte. Einzelne Rechte können darunter gezielt erlaubt oder gesperrt werden.

Super-Admin-Rechte werden aus Sicherheitsgründen separat vergeben. Ein bestehender Super-Admin kann sie in der Benutzerliste übertragen oder einem zweiten Verantwortlichen zusätzlich geben.

Server / Mandantenmigration

Der Vereinsserver wird zentral verwaltet. Mitglieder können ihn in der App nicht ändern. Ein Vereinsadmin kann einen Wechsel beantragen; die Freigabe und endgültige Umschaltung erfolgen ausschliesslich durch den Plattform-SuperAdmin.

SuperAdmin-Freigaben

Ablauf: Antrag freigeben → Transferpaket herunterladen → auf dem Zielserver importieren → Zielserver prüfen → Umschaltung aktivieren. Erst die letzte Aktion leitet App-Logins auf den neuen Server.

Transferpaket auf diesem Server importieren

Das Paket enthält die Daten und Medien genau eines Vereins sowie dessen App-Benutzerkonten inklusive Passwort-Hashes. Nur über eine sichere HTTPS-Verbindung und nur durch SuperAdmins verwenden.

Vereinsbackup

Enthält nur Daten und Medien des aktuell ausgewählten Vereins. Benutzerpasswörter, Push-Geräte, Vereinsabrechnungen, temporäre Snapshots sowie System- und Sicherheitsdaten werden nicht exportiert.

Vereinsbackup importieren

Nur für denselben Verein auf derselben Serverinstanz. Vor dem Import wird automatisch eine vollständige Sicherheitskopie erstellt. Der Import führt die Sicherung mit vorhandenen Vereinsdaten zusammen und löscht keine neueren Einträge.

Datenbank-Backups

Nur für Super-Admins. Automatische Sicherung mindestens einmal täglich. Die ältesten Sicherungen werden nach Erreichen der eingestellten Anzahl automatisch entfernt. Vereinsadmins erhalten keinen Zugriff auf die Gesamtdatenbank.

Backups werden geladen …

Backup wiederherstellen

Nur vollständige Datenbank-Backups dieser Vereinsinstanz verwenden. Vor der Wiederherstellung wird automatisch eine zusätzliche Sicherheitskopie der aktuellen Datenbank erstellt. Nach erfolgreichem Restore werden alle Sitzungen abgemeldet.
